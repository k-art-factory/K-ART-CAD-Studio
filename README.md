## 起動方法
ZIPを展開し、`index.html` をChromeなどのブラウザで開いてください。インストールやサーバーは不要です。操作方法は画面右上の「? HELP」または `help.html` を参照してください。

## 主な機能
- 2D作図：直線・長方形・円・円弧・文字・寸法線・距離測定
- 編集：選択・移動・トリム・延長・オフセット・面取り・Undo/Redo
- レイヤー、グリッド、図形スナップ、数値作図
- 複数選択、グループ化・解除、数値移動・コピー、図形プロパティ編集
- ホーム位置登録・復帰、左右パネルの折りたたみ、日英言語切り替え
- JSON保存・読込、SVG/PNG出力、限定的なDXF入出力
- A4〜A0の印刷プレビュー・印刷・PDF保存、縮尺、図面枠・表題欄
- ブラウザ内の自動バックアップ・手動復元

## よく使うショートカット
- Ctrl+G：グループ化 / Ctrl+Shift+G：解除
- Ctrl+C / Ctrl+V：図形のコピー・貼り付け（CAD内部、10mmずらす）
- Ctrl+Z / Ctrl+Y：元に戻す・やり直し
- Ctrl+S / Ctrl+O：保存・開く
- F1：HELP / Home：ホームへ / Delete：削除 / Esc：キャンセル
- Shift+クリック：複数選択 / 図形ダブルクリック：プロパティ表示
その他はHELPの「ショートカット」を参照してください。

## 重要な制限と注意
- DXFは基本図形（LINE/CIRCLE/ARC/TEXT等）の限定対応です。複雑なDXF、寸法・グループ等の完全な互換性は保証しません。
- 自動バックアップは同じブラウザ内の保存領域を利用します。閲覧データ削除・プライベートモード・端末変更等で失われることがあります。重要な図面はJSON形式でも保存してください。
- 印刷の実寸は、用紙・プリンタ・ブラウザ設定に依存します。印刷倍率100%、余白なし、ヘッダー/フッターなしを推奨し、必ず実寸をご確認ください。
- 英語切り替えは一部メッセージが日本語のままです。
- 建築・土木・製造等の業務で使う場合は、寸法・図面・出力結果を利用者自身で検証してください。
- ブラウザ/OSによって一部ショートカットが標準操作と競合することがあります。
